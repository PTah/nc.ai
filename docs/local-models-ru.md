# Свои модели (Custom) — простыми словами

Эта страница для тех, кто подключил **свой сервер** — Ollama, LM Studio или vLLM (на этом же ПК, в LAN
или на своём хосте) — и хочет понять: **почему иногда тормозит**, что такое **Lite**, и как работает
**автовыбор модели**.

---

## Зачем вообще свой сервер?

Облачные модели (DeepSeek, Z.ai…) быстрые, но данные уходят в интернет.

**Custom** = модель крутится там, где вы её развернули (например `192.168.128.5:11434`). Данные наружу
не уходят. Минус: скорость зависит от вашей видеокарты и размера модели. Такой сервер может быть и
совсем локальным, и на VPS — важно только, чтобы он отдавал OpenAI-совместимый API.

---

## Индикатор рядом с Rules

Когда выбран Custom, слева от `Rules Total/Applied` появляется плашка, например:

`Custom 85 tok/s · 420 ms · VRAM`

Цвета:

| Цвет | Значит |
|------|--------|
| **Зелёный** | Всё ок: модель в видеопамяти, отвечает быстро |
| **Жёлтый** | Средне: холодный старт или не очень быстро |
| **Красный** | Плохо: очень медленно (часто считает на процессоре, не на GPU) |
| **Бордовый** | Совсем плохо: сервер не отвечает или «висит» |

Кликни по плашке — проверка запустится снова.  
Раз в ~2 минуты NotCursor сам обновляет её, пока выбран Custom.

### Откуда берутся цифры?

Программа делает то же, что мы делали руками:

1. Спрашивает Ollama: «модель уже в видеопамяти?» (`/api/ps`, поле `size_vram`)
2. Шлёт короткий запрос «скажи ok» и смотрит время и скорость токенов

Это **не** полный агент с tools — только быстрый термометр.

## Lite (Custom lite) — что это простыми словами

Агент в NotCursor умеет две «комплектации»:

| | Полный режим (Lite **выкл**) | Lite **вкл** |
|---|---|---|
| System prompt | полный, со всеми правилами проекта | короткий, минимум правил |
| Инструменты | все (файлы, поиск, git, терминал, ssh, web, todo) | ~12: файлы, поиск, `git status/diff/log`, `ask_user` |
| Терминал / ssh / web / commit | есть | **нет** |
| Project map | полная | урезанная |
| Когда лучше | модель уверенно зовёт инструменты (qwen2.5-coder 7B/14B и больше) | совсем слабая модель, мало VRAM, нужно быстрее |

**По умолчанию Lite выключен** — свой сервер работает как облачный агент.

Включается галочкой **Custom lite** в топбаре (рядом с Auto-models) и хранится в `settings.json`
(`localLite`). Меняет только то, что уходит в модель: ни файлы, ни настройки проекта Lite не трогает.

**Когда Lite помогает:** если сервер слабый и агент «зависает» на длинном промпте, а вы готовы к тому,
что часть инструментов недоступна (например, терминалом он работать не будет).

**Когда Lite вредит:** модель перестаёт звать инструменты и начинает писать «Вероятно…» вместо чтения
файлов. Это типично для coder-моделей 7B/14B: у них полный набор инструментов работает лучше короткого.
Симптом — ответы-догадки: выключаем Lite, начинаем **новый чат** (старые «Вероятно…» в истории заражают
следующие ответы).

**Быстрый выбор:** qwen2.5-coder 7B/14B → Lite **выкл**; модель меньше 7B или мало VRAM → попробовать
Lite **вкл** и сравнить по одному и тому же запросу; сомневаетесь — оставьте **выкл**.

---

## Почему смена модели, а ответ тот же?

1. В истории уже лежит старый длинный ответ без tools — модель его **копирует**, даже 14B вместо 7B.
2. NotCursor теперь такие ответы в контексте **затирает** заглушкой и на первом шаге Custom требует tool call.

Что сделать сейчас:

1. Пересобери приложение с этими правками.
2. **Новый чат** (обязательно).
3. Custom lite **выкл**, Auto-models **выкл**, модель с `tools`.
4. Спроси: «прочитай README.md и скажи версию» — должны появиться tool-блоки.

---

## Auto-models для Custom

Галочка **Auto-models** теперь работает и для Custom.

Простыми словами:

1. NotCursor смотрит, какие модели есть на сервере.
2. Берёт те, у которых Ollama написала capability **`tools`** (умеют вызывать инструменты).
3. Среди них любит имена с **coder** / **code**.
4. На **простой** вопрос — берёт **меньшую** (быстрее), например `qwen2.5-coder:7b`.
5. На **сложный** (рефакторинг, много файлов, длинный прогон) — **побольше**, если такая есть с `tools`.

### Важно про deepseek-coder-v2:16b

На многих Ollama эта модель **без** capability `tools`.  
Для агента NotCursor она **не выбирается автоматически** — иначе снова будут «кривые» ответы без нормальных tool call.

Её можно выбрать **вручную** в списке Model, но для агента лучше модель с `tools` (как Qwen Coder).

Если Auto-models **выключен** — всегда используется модель, которую ты выбрал в Settings.

## Если модель пишет «Вероятно…» и не читает код

Частые причины:

1. **Слабая модель** не вызывает tools — гадает по общим знаниям.
2. **Auto-models** «залип» на старой модели (в чате казалось, что сменил модель, а агент крутил прежнюю).
3. В **истории чата** уже куча догадок — модель продолжает в том же стиле.

Что сделать:

1. Settings → Custom → выбрать модель с capability **`tools`** (например `qwen2.5-coder:7b`).
2. Смена модели в Settings **выключает Auto-models** — дальше идёт именно выбранная.
3. **Новый чат** (или Clear) — сбросить историю «Вероятно…».
4. В ответе должны появиться блоки tools (`read_file` / `grep`…). Если их нет — модель всё ещё гадает.

NotCursor при Custom один раз **переспрашивает** модель, если она ответила без tools.

## Холодный старт (почему первый ответ долгий)

Ollama может **выгрузить** модель из видеопамяти после простоя (часто ~5 минут).

Следующий запрос снова **загружает** гигабайты в GPU — это 5–30 секунд сверху. Это и есть холодный старт.

На сервере можно держать модель дольше:

```powershell
[Environment]::SetEnvironmentVariable("OLLAMA_KEEP_ALIVE", "30m", "Machine")
```

Потом полностью перезапустить Ollama.

Если в индикаторе есть **cold** / жёлтый цвет и большой `loadMs` — почти наверняка это оно.

## Несколько своих серверов

В Settings → Custom можно добавить несколько серверов (дом, ноут, VPS, LM Studio…).

Каждый выглядит как `Custom: имя` в списке провайдеров.  
Токены (если нужны) хранятся отдельно на каждый сервер.

Подробнее технически: [ollama.md](./exchange-protocols/ollama.md).

## Мини-шпаргалка

| Вопрос | Ответ |
|--------|--------|
| Почему зелёный, но агент всё равно думает минуту? | Индикатор меряет короткий ping. Агент делает много шагов с tools — это дольше. Lite уже сокращает tools. |
| Почему «Вероятно…» и не читает код? | История с догадками / Lite / модель без tools. Новый чат, Lite выкл, модель с `tools`. |
| Зачем Custom lite? | Опционально для слабых моделей. На 7B/14B coder лучше **выкл**. |
| Почему не берёт 16B? | Часто нет `tools` у Ollama. Смотри индикатор / список моделей. |
| Как прогреть сервер? | Кликни плашку Custom или Test connect; либо сделай любой короткий запрос. |
| Данные уходят в облако? | При Custom — нет, только на ваш сервер (Ollama/LM Studio/vLLM). |
