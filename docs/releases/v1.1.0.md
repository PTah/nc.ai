## NotCursor 1.1.0 — nc.ai

### Зачем

Минорный релиз: два приёма из DreamTeam, которые полезны без «кучи денег на токены»,
плюс два накопившихся улучшения.

### Что появилось

- **Режим «заканчиваем».** Короткое «завершай / заканчивай / закругляйся / хватит / stop /
  finish up» включает `finishMode`: новые `run_terminal` и `task` не стартуют, инструмент сразу
  возвращает «собери итог из того, что уже есть», в чат уходит один notice. Правки файлов при
  этом не блокируются — текущую работу можно закончить. Отрицания («не заканчивай») и длинные
  сообщения не триггерят.
- **Напоминание цели.** Цель запроса (до 400 символов) добавляется в системный промпт прогона:
  «Goal of this request (do not drift away from it): …». Длинный контекст больше не уводит
  агента; напоминания про открытые todo уже работают через `todo_nudge`.
- **Кликабельные ссылки.** `Markdown` перехватывает клик по `<a>` и отдаёт URL системному
  браузеру (`BrowserOpenURL`), голые URL автолинкуются через `remark-gfm`; ссылки подчёркнуты
  и меняют толщину подчёркивания на ховере.
- **SSH без лишних логинов.** `ssh_exec` держит одно соединение на хост (`host|port|user|
  identity`) и открывает только каналы; простой закрывается reaper-ом через 10 минут. В
  описании инструмента — просьба батчить команды на одном хосте в один вызов.

### Проверка

- `go build ./...`, `go test ./internal/agent/ ./internal/sshx/ ./internal/tools/` — зелёные.
- `npm --prefix frontend run build` — ок.
- `wails build -o NotCursor-1.1.0.exe` — ок.

### Ограничения

- Потолок денег с паузой (#4) и зависимости задач в `todo_write` (#3) — следующий заход,
  в 1.1.0 их нет.
- «Заканчиваем» — эвристика по короткой команде в начале сообщения.
