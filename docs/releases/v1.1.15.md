# NotCursor.ai 1.1.15

## Windows: белое окно после долгого простоя

Если приложение долго было свёрнуто или без фокуса, WebView2 иногда поднимал
пустую (белую) поверхность при развороте — рамка окна жила, Go-бэкенд работал,
а UI не рисовался.

Что сделано:

- при возврате фокуса / `visibilitychange` — форс-перерисовка и лёгкий nudge
  размера окна;
- после долгого простоя — мягкий `WindowReloadApp` (фронт перезагружается,
  процесс Go и черновики на диске остаются);
- после сна Windows — тот же soft-reload через `OnResume`;
- флаг WebView2 `CalculateNativeWinOcclusion` отключается при старте, чтобы
  реже подвешивать GPU/render у свёрнутого окна.

## Без изменений поведения агента

Workspace из нескольких папок, параллельные прогоны и остальной функционал
1.1.14 — как были.

## Архив чатов: без фриза после отправки в архив

После архивации чата приложение на несколько секунд «замирало»: не
переключалась раскладка, не срабатывал клик по полю ввода. Причина — список
архивов тянул полный транскрипт и историю модели **всех** архивных чатов сразу,
и фронт синхронно разбирал их в главном потоке.

- список архивов теперь отдаёт только метаданные (название, проект, дата,
  число сообщений);
- полный транскрипт грузится лениво при открытии конкретного архивного чата
  (`App.LoadArchivedChat` → `chatstore.LoadArchived`);
- убрана квадратичная сортировка списка архивов.
