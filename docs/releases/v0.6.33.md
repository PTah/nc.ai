## NotCursor 0.6.33 — nc.ai

### Локальные модели: ответ больше не пропадает и не теряется

- Подробное описание, которое модель уже выдала после чтения файлов, **не стирается**.
  Повтор с требованием «прочитай файлы» срабатывает только если в прогоне не выполнено
  ни одного инструмента; раньше любой ответ длиннее 80 символов считался догадкой — текст
  пропадал из чата, а модель просили ответить коротко.
- «Local down» в шапке больше не мигает во время длинного ответа: проба здоровья не шлёт
  свой запрос, пока идёт прогон (у Ollama один слот, проба стояла в очереди и не успевала
  за 45 с). Во время прогона статус — «Local занят».
- Пустой финальный ответ (`finish=stop`): сначала один повтор «ответь текстом», затем
  понятная ошибка с причиной (переполненный контекст или ответ целиком в thinking)
  и что делать.
- Thinking-модели на Ollama: трасса размышлений читается из поля `reasoning` — раньше она
  игнорировалась, и ответ выглядел пустым.
- Контекст локального сервера задаётся в Settings → Local (поле **Context**, `num_ctx`):
  приложение предупредит, когда промпт подошёл к окну. Для Ollama контекст поднимается
  переменной `OLLAMA_CONTEXT_LENGTH` — в OpenAI-совместимом режиме `num_ctx` не принимается.
- Если Auto-models подменил выбранную локальную модель, в чат уходит пояснение: какая
  модель взята, почему и как закрепить свою.

### Список задач (ToDo) обновляется по ходу работы

Агент обязан помечать пункт `in_progress` в момент старта и `completed` сразу после; если список не менялся четыре шага подряд, он получает напоминание обновить его. Раньше список мог остаться в исходном состоянии (0/8) до конца прогона.

### Не предлагаем «обновиться» на более старый релиз

Если на GitHub latest — **0.6.32**, а локально уже **0.6.33**, приложение больше не показывает баннер
«версия та же, но другая сборка»: хеши всегда разные у разных версий, и это не повод откатываться.

Предложение обновления только когда:

1. на GitHub номер версии **больше**, или
2. номер **тот же**, но sha256 бинарника в релизе другой (перезаливка файла).

### Выбор шрифтов в Settings

В **Settings → Interface**:

- **UI font** — Segoe UI / Verdana / Tahoma / Arial / System UI;
- **Mono font** — Consolas·Menlo / Lucida Console / Consolas / Courier New / Cascadia Mono.

### Автообновление на Windows

Helper подмены запускается без `DETACHED_PROCESS` (иначе PowerShell 5.1 сразу умирает),
с `CREATE_BREAKAWAY_FROM_JOB`, пишет `swap.log`, копирует exe и до трёх раз пытается
запустить приложение из его каталога. Старые сборки с багом подменщика сами себя не
починят — один раз поставьте этот релиз вручную.

### Также в выпуске (с 0.6.32)

- «Новости провайдеров» в настройках (DeepSeek, Z.AI, OpenRouter, Qwen).

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.6.33-windows-amd64.zip` и распаковать в любую папку.
2. Запустить `NotCursor.exe`.
3. Дальше обновления — кнопкой из приложения.
