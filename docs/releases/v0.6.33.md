## NotCursor 0.6.33 — nc.ai

### Выбор шрифтов в Settings

В **Settings → Interface**:

- **UI font** — Segoe UI / Verdana / Tahoma / Arial / System UI;
- **Mono font** — Consolas·Menlo / Lucida Console / Consolas / Courier New / Cascadia Mono.

### Автообновление на Windows

Helper подмены запускается без `DETACHED_PROCESS` (иначе PowerShell 5.1 сразу умирает),
с `CREATE_BREAKAWAY_FROM_JOB`, пишет `swap.log`, копирует exe и до трёх раз пытается
запустить приложение из его каталога. Старые сборки с багом подменщика сами себя не
починят — один раз поставьте этот релиз вручную.

### Также в выпуске (с 0.6.32)

- «Новости провайдеров» в настройках (DeepSeek, Z.AI, OpenRouter, Qwen).

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.6.33-windows-amd64.zip` и распаковать в любую папку.
2. Запустить `NotCursor.exe`.
3. Дальше обновления — кнопкой из приложения.
