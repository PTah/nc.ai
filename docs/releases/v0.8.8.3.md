## NotCursor 0.8.8.3 — nc.ai

### Баланс в шапке — понятными словами

Три числа `bal / grant / topup` заменили на человеческие подписи:

- **баланс** — сколько доступно сейчас (сумма бонуса и пополнения);
- **бонус** — бесплатные/подарочные средства от DeepSeek (тратятся первыми);
- **пополнение** — деньги, которые вы сами внесли.

У каждой цифры — подсказка при наведении, а «пополнение» по-прежнему краснеет,
когда остаётся меньше $1. Суммы баланса теперь показываются аккуратно (`$5.20`,
`$0.012` вместо `$5.2000`); формат расходов не трогали.

### Меньше шума во время прогона

Лента «думанья» стала компактной:

- выполненные инструменты сворачиваются в **один блок «Исследовал · N шагов»**
  вместо череды строк «Запускаю команду / Читаю файл / Правлю файл»;
- блок не раскрывается сам — живым остаётся только текущий шаг;
- карточки «этап» больше не копятся: очередная заменяет предыдущую, текст этапа и
  так содержит накопительные итоги.

Подробности по инструментам доступны по клику на блок. Строки-нарративы агента
регулируются отдельно: **Settings → Agent → Пояснения шагов** (Авто / Всегда / Никогда).

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.8.8.3-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
2. Ключи провайдеров — **Settings → Providers** (Windows Credential Manager).

### Установка (macOS 12+, Apple Silicon и Intel)

1. Скачать `nc.ai-0.8.8.3-macos-*.zip`, распаковать.
2. Перенести `NotCursor.app` в «Программы», запустить (ad-hoc подпись: правый клик → «Открыть»).
