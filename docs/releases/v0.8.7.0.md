## NotCursor 0.8.7.0 — nc.ai

### Остаток баланса обновляется сам: OpenRouter и Z.ai — как DeepSeek

Раньше периодический опрос баланса был только у DeepSeek: у OpenRouter и Z.ai остаток
подтягивался на старте, при смене провайдера и по кнопке **Refresh balance**. Во время долгой
сессии можно было не увидеть, что кредиты кончились.

- Фоновый таймер (5 минут) опрашивает баланс **активного** провайдера: DeepSeek, OpenRouter, Z.ai.
- Опрашивается только выбранный провайдер — лишние запросы к API остатка не уходят.
- Для OpenRouter это `GET /api/v1/credits` (нужен ключ с доступом к management; если ключ обычный,
  API отвечает 401/403 и в настройках видно, почему баланс недоступен).

### Каталог OpenRouter целиком: группировка и фильтр по категориям

Список моделей OpenRouter был курированным: `FilterCodingModels` оставлял только «кодерские» id
(coder / qwen / deepseek / devstral / codestral), поэтому в настройках было ~50 строк.

- Теперь читается **весь** каталог `GET /api/v1/models` (фильтр `supported_parameters=tools`
  снят), а поддержка инструментов определяется по каждой модели отдельно.
- Категория выводится из `architecture.modality` (что модель отдаёт на выходе) и id:
  **Кодинг / Рассуждения / Общие чаты / Картинки / Аудио / Видео / Прочее**.
  Vision-модели (`text+image->text`) остаются текстовыми: они читают картинки, а не рисуют их.
- В настройках список сгруппирован (`optgroup`) и есть фильтр по категории; каталожные
  кодинг-модели идут первыми, медиа-группы ограничены по размеру, чтобы список остался рабочим.
- Каждая строка каталога несёт `category` и `tools` — этим пользуется предупреждение ниже.

### Предупреждение, когда модель не подходит задаче

Проект — кодинг-агент, поэтому в списке видно всё, но не всё годится для работы. Теперь
приложение говорит об этом прямо:

- в настройках под выбором модели: если категория — Картинки/Аудио/Видео (модель не сможет править
  файлы и запускать команды), если у модели нет tool calling, или если категория не Кодинг/Рассуждения;
- при отправке запроса: если текст похож на генерацию графики («нарисуй…», «сгенерируй картинку»,
  `draw`, `generate an image`), а выбрана текстовая/кодинг-модель — предупреждение уходит в чат,
  с подсказкой переключиться на модель из группы «Картинки».

### Эскалация на сильную модель — не только у DeepSeek

`bumpToStrong` (повтор tool call, два провала инструментов, пустой ответ, битый tool call) работал
только для DeepSeek. Теперь подъём на сильную модель есть и у остальных провайдеров:

| Провайдер | Слабая (стартовая) | Сильная (эскалация) |
|---|---|---|
| OpenRouter | `qwen/qwen3-coder-flash:floor` | `qwen/qwen3-coder:floor` |
| Z.ai | `glm-4.7-flash` | `glm-5.3` |
| Qwen | `qwen-turbo` / `qwen-plus` | `qwen-max` |
| Yandex | `yandexgpt` / `lite` | `qwen3-235b` |
| DeepSeek | `deepseek-flash` | `deepseek-v4-pro` |

Сообщение в чате теперь называет конкретную модель, на которую подняли
(например: «Поднял на OpenRouter qwen/qwen3-coder:floor: повтор одного и того же tool call.»).
Авто-маршрутизация OpenRouter (`PickOpenRouterModel`: длинный прогон / сложный запрос / много
путей → сильная модель) продолжает работать как раньше.

### Тесты

Добавлен `internal/llm/providers/openrouter/catalog_test.go`: категория по модальности
(генерация картинки ≠ vision), определение tool calling, порядок каталога и ограничение медиа-групп.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.8.7.0-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
2. Ключи провайдеров — **Settings → Providers** (Windows Credential Manager).

### Установка (macOS 12+, Apple Silicon и Intel)

1. Скачать `nc.ai-0.8.7.0-macos-*.zip`, распаковать.
2. Перенести `NotCursor.app` в «Программы», запустить (ad-hoc подпись: правый клик → «Открыть»).
