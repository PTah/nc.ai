## NotCursor 0.8.7.8 — nc.ai

### Почему обновление качалось «как с GitHub», хотя зеркало настроено

Инцидент 16.10.2026, 22:14:54. В настройках включено своё зеркало релизов, но в `agent.log`:

```
16.10.2026 22:14:54 update check source=github latest=0.8.7.7 available=true   ← проверка ушла на GitHub
16.10.2026 22:16:37 update check source=mirror latest=0.8.7.7 available=false
```

Проверка обновлений устроена так: сначала опрашивается зеркало, и **при любой** его ошибке
молча берётся GitHub. Зеркало в тот момент не ответило (рядом шла заливка релиза в Gitea),
фолбэк не оставил ни строчки в логе — а `Info.AssetURL` после фолбэка указывает на GitHub,
поэтому и скачивание пошло с него. Замеры одного и того же файла
(`nc.ai-0.8.7.7-macos-arm64.zip`, 7,16 МБ):

| Источник | Время | Скорость |
|---|---|---|
| своё зеркало, `192.168.x.x:3000` по LAN | 0,17 с | 42 МБ/с |
| GitHub | 2,03 с | 3,5 МБ/с |

Что изменилось:

- **Зеркало опрашивается раундами** (`mirrorRounds = 2`, пауза 600 мс, таймаут 20 с на раунд, внутри
  раунда — до 3 попыток): одиночный сбой домашнего Gitea (заливка релиза, перезапуск) больше не
  отправляет за обновлением на GitHub;
- **причина отказа зеркала больше не теряется**: она едет в `Info.MirrorError`, и в `agent.log`
  появляется строка `update mirror failed err=… (source=github)`;
- **источник виден в интерфейсе**: в баннере обновления — «Источник: своё зеркало (LAN)» либо
  «Источник: GitHub — зеркало не ответило (…), скачивание будет медленнее», в Settings → Обновления
  под кнопкой «Проверить обновления» — строка «Последняя проверка: …»;
- текст про «другую сборку» больше не говорит «на GitHub», когда релиз взят с зеркала.

Теперь молчаливого перехода на GitHub нет: если зеркало отвалилось, это видно и в логе, и в окне.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.8.7.8-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
2. Ключи провайдеров — **Settings → Providers** (Windows Credential Manager).

### Установка (macOS 12+, Apple Silicon и Intel)

1. Скачать `nc.ai-0.8.7.8-macos-*.zip`, распаковать.
2. Перенести `NotCursor.app` в «Программы», запустить (ad-hoc подпись: правый клик → «Открыть»).
