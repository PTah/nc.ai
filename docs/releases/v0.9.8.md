## NotCursor 0.9.8 — nc.ai

### Зачем

Две проблемы в анализе новостей:

- Галочка «Анализ новостей ИИ» отжималась сама. `GetSettings` — рукописная `map`, и поля
  `newsAI` в ней не было: после любого перечитывания настроек фронт получал `undefined`,
  `Boolean(undefined)` → `false`, чекбокс сбрасывался. Настройка при этом сохранялась — просто
  UI её не видел.
- Анализ читал только заголовок. Для «ушла модель X» это догадка, а не разбор; для блог-записей
  текст статьи вообще не подтягивался.

### Что появилось

- `GetSettings` отдаёт `newsAI` — галочка больше не отжимается, состояние переживает
  перечитывание настроек и перезапуск.
- **Настоящее чтение:** для блог/новостных записей тянется текст статьи по URL
  (`netx.FetchURL`, обрезка 6 КБ). Если источник недоступен — ИИ прямо говорит, что по
  заголовку можно только предположить, вместо выдумывания.
- **Catalog-записи** («ушла/появилась модель») дополняются актуальным списком моделей
  провайдера, чтобы ИИ предложил замену.
- **Анализ по четырём пунктам** с контекстом проекта (активный провайдер, модель, экономия на
  дешёвых моделях): (1) функциональность агента — tools/vision/файлы/reasoning, (2) цены и
  доступность, (3) убрали/добавили модель и чем заменить, (4) нужно ли NotCursor и как
  использовать. Ответ 2–4 предложениями; до 8 записей за обновление, таймаут 60 с.

### Проверка

- `go vet ./...`, `go test ./...` — зелёные.
- `wails build` — ок; биндинги перегенерированы.

### Ограничения

- Если активный провайдер не настроен, фоновая галочка по-прежнему молча ничего не делает —
  это отдельная правка (нужна пометка в UI).
- Анализ не попадает в историю чата и не тратит контекст диалога — это фоновый дайджест.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.9.8-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
2. Settings → News: включить «Анализ новостей ИИ», нажать «Обновить» — под новыми записями
   появится разбор с чтением источника.
