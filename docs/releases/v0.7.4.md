## NotCursor 0.7.4 — nc.ai

### Новый проект теперь можно начать, а не только открыть

В левой панели вместо кнопки **Open Project…** — кнопка **Project ▾** с двумя пунктами:
**Open project…** (как раньше — существующая папка) и **Create project…**.

Раньше начать проект, папки которого ещё нет, было нечем: оставалось создать папку в Finder,
а потом открывать её в приложении. Теперь это один диалог внутри NotCursor.

- **Create project…** — имя проекта (оно же имя папки), поле «Где создать» и кнопка **Создать**
  (или `Enter`). Папка создаётся и **сразу открывается**: дерево файлов, чат, терминал — можно
  работать без лишних шагов.
- **«Где создать» подставляется автоматически**: папка прошлого создания → родитель открытого
  проекта → домашняя папка. В обычном случае достаточно ввести имя. Сменить место — «Обзор…».
- Превью «Создадим: …» показывает полный путь ещё до создания папки.
- Имя папки проверяется до создания: пустое имя, `.`/`..`, разделители пути (`/`, `\`), символы
  `< > : " | ? *`, хвостовые точка/пробел и зарезервированные имена Windows (`CON`, `NUL`,
  `LPT9`) не проходят.
- Если папка с таким именем уже есть, приложение не открывает её молча, а подсказывает
  воспользоваться **Open project…** — случайно войти не в тот проект нельзя.
- Пустой список проектов тоже подсказывает путь: «Project» → Open project / Create project.

### Мелочи

- Диалог открытия проекта стартует в осмысленной папке (раньше — где получится).
- Из `frontend/src/App.css` убран UTF-8 BOM: все файлы репозитория — UTF-8 без BOM, кроме
  исходников PowerShell (`.ps1`), где BOM нужен для PS 5.1.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.7.4-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
2. Ключи провайдеров — **Settings → Providers** (Windows Credential Manager).

### Установка (macOS 12+, Apple Silicon и Intel)

1. Скачать `nc.ai-0.7.4-macos-arm64.zip` или `nc.ai-0.7.4-macos-universal.zip`, распаковать.
2. Перенести `NotCursor.app` в «Программы», запустить (ad-hoc подпись: правый клик → «Открыть»).
