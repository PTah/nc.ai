## NotCursor 0.8.4.0 — nc.ai

### Субагенты (MVP)

Длинный поиск по репозиторию больше не обязан пожирать контекст родительского чата.

- Новый инструмент **`task`**: родитель делегирует исследование во вложенный прогон.
- У ребёнка свой контекст, лимит шагов и read-only tools (по умолчанию).
- В ленте — сворачиваемая карточка «Подагент: …» с шагами и сводкой.
- Settings → **Subagents (tool task)** — по умолчанию **выкл.**; лимит шагов / число task за прогон / опция записи.

Глубина ровно 1 (ребёнок не может звать `task`). На Local дети идут последовательно (один слот модели).
