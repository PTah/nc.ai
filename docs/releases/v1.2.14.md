## NotCursor 1.2.14 — nc.ai

### MCP на macOS/Linux: `npx` тоже без лишнего процесса

- **Разбор `npx`-шима теперь понимает Unix-форму.** Раньше `npxCliFromShim` знал только
  npm-шим для Windows (`%~dp0%`, `.cmd`) и на macOS/Linux возвращал пустой путь: `npx` там —
  shell-скрипт, который ссылается на `$basedir/node_modules/npm/bin/npx-cli.js`. Теперь
  разбираются обе формы, и `npx …` на Unix тоже превращается в прямой `node <npx-cli.js>`,
  без дополнительного процесса-обёртки (фикс 1.2.13 работал только на Windows).
- **Путь к лончеру проверяется на существование** — если шим ссылается на отсутствующий
  `npx-cli.js`, поведение остаётся прежним (запуск через `npx`), ошибки нет.
- **Тесты `internal/mcp` снова проходят на macOS.** Фикстуры шимов стали OS-зависимыми,
  добавлен кросс-платформенный тест на Unix-шим, а тест `.cmd`-шима пропускается на не-Windows —
  этот код исполняется только под `runtime.GOOS == "windows"`.

### Установка

macOS: `nc.ai-1.2.14-macos-arm64.zip` (Apple Silicon) или `nc.ai-1.2.14-macos-universal.zip`
(Intel + Apple Silicon), распаковать в `/Applications`.
Windows 10/11 x64: `nc.ai-1.2.14-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
