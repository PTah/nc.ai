## NotCursor 1.0.2 — nc.ai

### Что нового

- **Провайдер Kimi (Moonshot).** OpenAI-совместимый клиент `api.moonshot.ai/v1`:
  `chat/completions` со стримом, `GET /models` для каталога, `GET /users/me/balance`
  для баланса. Ключ и модель — в Settings, как у DeepSeek: `SaveKimiKey`,
  `ClearKimiKey`, `SaveKimiModel`, статус `kimiKeySet`.
- **Баланс в верхней панели** для Kimi: доступно / зачислено (voucher) / внесено (cash),
  плюс `BalanceDetail` с текстом от API, если разбор не сошёлся.
- **Auto-models** знает Kimi: `kimi-k3.1-pro` — сложные задачи и vision,
  `kimi-k3.1-pro-highspeed` — быстрый дефолт, `kimi-k3` — прошлый флагман,
  `kimi-k2.7-code` — код.
- **Стоимость** считается по своему sheet в `costing` (`usage.cost` API не отдаёт),
  поэтому расход виден в статистике прогона наравне с остальными провайдерами.
- **Модель провайдера на чат** сохраняется и восстанавливается вместе с транскриптом.
- **Документация:** `docs/exchange-protocols/kimi.md` — endpoint, headers, особенности
  (thinking всегда включён, `reasoning_effort` вместо `thinking{}`,
  `reasoning_content` в истории, баланс, ограничение K2-code для новых аккаунтов).

### Проверка

- `go test ./internal/llm/providers/kimi/...` — баланс и разбор ответа (фикстуры).
- `npx tsc --noEmit` (frontend) — чисто; биндинги `App.d.ts`/`App.js`/`models.ts`
  перегенерированы вместе с кодом.
- `./build.sh` — macOS 1.0.2, версия в бандле и в `About` совпадает с тегом.
