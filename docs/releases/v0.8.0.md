## NotCursor 0.8.0 — nc.ai

### Рабочее пространство из нескольких папок

Комплекс репозиториев (`ssh-monitor`, `seaca`, `rdp-login-monitor`,
`security-agent-center`) часто живёт рядом в `d:\soft\...`, но для агента это были
разные проекты. Теперь несколько папок можно объединить в одно рабочее
пространство и работать с ним как с одним репозиторием.

- **Menu → Project → Add folder to workspace…** — выбрать папку и добавить к
  текущему проекту. Первая (главная) папка остаётся якорем: к ней привязаны чаты.
- В той же секции **Project** виден список папок рабочего пространства, лишнюю
  можно убрать крестиком.
- Объединённые папки переживают перезапуск: их список хранится в настройках.

Как это работает для агента:

- дерево проекта показывает каждый корень отдельной папкой вверху;
- поиск (`find_files`, `glob`, `grep`), чтение и запись идут по **всем** корням;
- пути в мульти-корневом режиме идут с префиксом-именем папки
  (`ssh-monitor/internal/...`), поэтому видно, откуда файл;
- у одного корня всё как раньше — пути остаются обычными, без префикса.

### Кнопка «Project» → меню **Menu**

Левая панель оставлена под одно — список проектов. Всё остальное собрано в одну
кнопку **Menu** в её шапке:

| Секция | Пункты |
|---|---|
| **Project** | Open project…, Create project…, Clone repository…, Add folder to workspace… |
| **File** | Archived chats, Show/Hide files, Exit |
| **Settings** | Settings, Model prices |
| **Help** | About |

Кнопки `Archived chats` / `Show files` / `Model prices` ушли из подвала панели —
искать их больше не нужно в двух местах.

### Multitask: несколько запросов в одном чате

Раньше чат мог вести один прогон за раз: второй вопрос ждал в очереди. Теперь
запросы в **одном чате** выполняются параллельно.

- каждый запрос идёт своей «дорожкой»: своё мышление, свои вызовы инструментов,
  свой ответ — они не перемешиваются;
- дорожка вливается в транскрипт чата, когда прогон завершился;
- **Stop** останавливает все активные запросы этого чата;
- параллельность есть и между чатами/проектами — как и раньше, фоновые прогоны
  продолжаются, пока вы работаете в другом чате.

### Не оборванные ответы

Если модель упиралась в лимит длины (`finish_reason=length`), ответ обрывался на
полуслове, а прогон завершался ошибкой. Теперь агент сам дописывает хвост с того
же места (до 3 продолжений подряд, без повторов), а если даже так не помещается —
показывает текст как есть и предлагает сказать «продолжи».

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.8.0-windows-amd64.zip` и распаковать в любую папку.
2. Запустить `NotCursor.exe`.
3. Дальше обновления — кнопкой из приложения.
