## NotCursor 1.0.8 — nc.ai

### Что изменилось

Фоновая проверка репозиториев стала полностью невидимой и перестала показывать чип в шапке.

- `git fetch` и `git status` запускаются **без консольного окна** (`gitx.ConfigureCmd`:
  `HideWindow` + `CREATE_NO_WINDOW`) и с `GIT_TERMINAL_PROMPT=0` — никаких всплывающих окон и
  интерактивных запросов.
- Убран чип «репо: N» из шапки и фронтовый слушатель `repos:checked`: на экране ничего не
  появляется.
- Если после `git fetch` у проекта появились **скачанные изменения** (`behind > 0`), в активный
  чат этого проекта пишется служебное сообщение: «в репозитории «X» скачаны новые изменения
  (N коммитов в upstream, ветка Y)». Фронт по событию `chat:updated` перечитывает транскрипт,
  если открыт именно этот проект.

### Проверка

- `go build ./...` — ок.
- `npm --prefix frontend run build` — ок.

### Ограничения

- Сообщение пишется в активный чат проекта; если у проекта ещё нет чата, пропускается.
- Проверка по-прежнему раз в 8 часов; первая — через 2 минуты после старта.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-1.0.8-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
