## NotCursor 0.8.7.6 — nc.ai

### Замок проекта: SVG вместо эмодзи

Значок замка слева от названия проекта был эмодзи (`🔒` / `🔓`) — он рисовался шрифтом, выглядел
по-разному в разных системах и не подчинялся цвету темы.

Теперь это `frontend/src/LockIcon.tsx` — один силуэт (корпус + дужка), где меняется только дужка:
закрытая «садится» на корпус, открытая обрывается выше него. Читается на 13 px, около 1 КБ, цвет
берётся из `currentColor`, то есть идёт за темой.

Поведение (оно уже было заложено в CSS `.nc-project-lock`, значок его просто унаследовал):

| Состояние | Значок | Когда видно |
|---|---|---|
| Проект на замке (`locked`) | закрытый замок | **всегда** (`opacity: 1`) |
| Проект открыт для записи | открытый замок | при наведении на строку проекта слева от названия |

Заодно:

- наведение подняло непрозрачность значка с `0.6` до `0.8` — тонкая обводка SVG на 0.6 выглядела
  бледнее, чем эмодзи;
- баннер «Проект … на замке» тоже перешёл на этот значок, окрашенный в янтарный цвет рамки
  предупреждения (раньше там был эмодзи внутри текста);
- размер задан в CSS (`.nc-project-lock svg` — 13×13, `.nc-locked-banner svg` — 14×14).

### Почему не ваши `locked.png` / `open.png`

Файлы из корня репозитория для этой задачи не подходят, и это проверено, а не на глаз:

- 1664×928, RGB, **без альфа-канала**, по 1.4 МБ каждый;
- содержимое занимает **весь кадр** (bbox 0,0 → 1660,924), фон не однотонный — это фотография или
  рендер со сценой; средний цвет по сетке 3×3 меняется плавно (края 200–237, центр ≈144,130,105),
  то есть замок в фоне, а не на плашке;
- кнопка замка в списке — **20×20 px**: фотография на таком размере превратилась бы в мутное пятно,
  а 2.9 МБ ушли бы в сборку.

Оба файла остались в корне untracked — их можно удалить.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.8.7.6-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
2. Ключи провайдеров — **Settings → Providers** (Windows Credential Manager).

### Установка (macOS 12+, Apple Silicon и Intel)

1. Скачать `nc.ai-0.8.7.6-macos-*.zip`, распаковать.
2. Перенести `NotCursor.app` в «Программы», запустить (ad-hoc подпись: правый клик → «Открыть»).
