## NotCursor 0.7.14 — nc.ai

### V4.1 Flash виден под своим именем

DeepSeek отдаёт модели служебными идентификаторами (`deepseek-flash`, `deepseek-v4-pro`), и в селекторах
модели показывались ровно такими строками — по ним не понять, что `deepseek-flash` это уже V4.1 Flash.
Теперь id остаётся для API, а на экран идёт человеческая подпись:

| id в API | Подпись в UI |
|---|---|
| `deepseek-flash` | DeepSeek V4.1 Flash |
| `deepseek-v4-pro` | DeepSeek V4 Pro |
| `deepseek-v4-flash` | DeepSeek V4 Flash (routed to V4.1 Flash) |
| `deepseek-v4-flash-vision-exp` | DeepSeek V4 Flash Vision Exp |
| `deepseek-chat` | DeepSeek Chat (legacy alias) |
| `deepseek-reasoner` | DeepSeek Reasoner (legacy alias) |

Подписи видны в шапке чата, в **«Модель чата»** и в Settings → DeepSeek. В запрос по-прежнему уходит id.
Незнакомый (только что выпущенный) id показывается как есть — без выдуманного названия, и попадает в
уведомление чата о смене каталога.

### «Refresh models» больше не молчит — у всех провайдеров

Если запрос к `/models` не отвечал (нет сети, просроченный ключ, таймаут), кнопка **Refresh models**
тихо подставляла встроенный список — внешне это выглядело как «нажал, и ничего не произошло». Теперь
рядом с кнопкой появляется строка с результатом, и так у всех провайдеров: DeepSeek, Z.ai, OpenRouter,
Qwen, Yandex AI Studio и Custom:

- `Список из API — моделей: 2.` — ответ получен, каталог актуальный;
- `Не удалось получить список моделей: <причина>. Показан встроенный список.` — запрос не прошёл;
- `Ключ <провайдер> не задан — показан встроенный список моделей.` — спрашивать нечего.

У Custom встроенного списка нет: если LAN-сервер (Ollama / Lemonade / LM Studio) не отвечает, в строке
будет причина, а не «показан встроенный список».

Тот же текст попадает в пилюлю у кнопки `↻ Models` в шапке, так что ошибка видна и без открытых
настроек.

Заодно снапшот каталога DeepSeek (`deepSeekModelsSeen`) обновляется **только по настоящему ответу
API**: раньше неудачное обновление записывало встроенный список как «увиденный», после чего реальное
изменение каталога уже не давало уведомления в чате. Само уведомление тоже перешло на подписи:
«новые: DeepSeek V4.1 Flash (deepseek-flash)».

### Мелочи

- порядок списка прежний: flash → pro → vision → остальные;
- «Refresh balance» (`GET /user/balance`) без изменений.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.7.14-windows-amd64.zip` и распаковать в любую папку.
2. Запустить `NotCursor.exe`.
3. Дальше обновления — кнопкой из приложения.
