## NotCursor 0.7.2 — nc.ai

### Стримят все провайдеры

Раньше печатал по мере генерации только профиль Local / custom (Chat Completions). Теперь
SSE-поток понимают все:

| Провайдер | Как стримит |
|---|---|
| DeepSeek | `stream: true` + `stream_options.include_usage` (usage последним чанком), `reasoning_content` — в «Думал» |
| Z.ai / GLM | `stream: true`, рассуждения GLM идут в «Думал» |
| Qwen (DashScope) | `stream: true` + `include_usage` |
| OpenRouter | `stream: true`, `usage.cost` приходит в потоке — стоимость шага считается как раньше |
| Anthropic Messages | своя событийная модель: `message_start`, `content_block_delta` (`text_delta`, `thinking_delta`, `input_json_delta`), `message_delta`, `message_stop` |
| Local / custom | как раньше |

Общий разбор Chat Completions вынесен в `internal/llm/openai_stream.go`, у Anthropic — свой
парсер (`internal/llm/providers/anthropic/stream.go`). Дельты текста и рассуждений идут в ленту
сразу, tool_calls собираются по индексам и работают так же, как в non-stream режиме.

Если эндпоинт не принимает `stream_options` (некоторые локальные и сторонние сборки отвечают
400), запрос автоматически повторяется в обычном режиме — прогон не падает, просто ответ
приходит целиком.

### Что проверить

1. Чат на DeepSeek: текст появляется по мере генерации, «Думал» наполняется отдельно.
2. Запрос с инструментами (прочитать файл) — вызов и результат проходят как обычно, стоимость
   шага на месте.
3. Профиль Anthropic: ответ печатается по мере генерации, thinking идёт в «Думал».
4. Профиль с локальным сервером, который не понял `stream_options`: ответ приходит целиком,
   ошибки нет.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.7.2-windows-amd64.zip` и распаковать в любую папку.
2. Запустить `NotCursor.exe`.
3. Дальше обновления — кнопкой из приложения.

### Дополнено в том же 0.7.2 (пересборка без смены номера)

- **Лимиты времени у команд:** `shell.Run` гасит всё дерево процессов (`taskkill /F /T` на
  Windows, `Setpgid` + `SIGKILL` на unix) и не залипает на потомках; `run_terminal` —
  120 сек по умолчанию, `timeout_sec` не больше 30 минут, ошибка подсказывает про
  `is_background=true`.
- **git не подвисает** и не вытаскивает окно Git Credential Manager: лимит 90 сек (300 сек
  на `push`/`pull`/`fetch`/`clone`), `GIT_TERMINAL_PROMPT=0`, `GCM_INTERACTIVE=never`,
  SSH в `BatchMode`. Свой `core.sshCommand` (или `GIT_SSH_COMMAND`) не перетираем — к нему
  лишь добавляется `BatchMode`, иначе push в remote с ключом из `~/.ssh/config` падал бы
  с «Permission denied (publickey)».
- **`read_lints` — 120 сек** вместо 25 (на холодном кэше `go vet` не укладывался),
  **`get_env_info` — 10 сек** на пробу тулчейна вместо 2 (npm на Windows не успевал).
- **Фоновые jobs** гасятся при закрытии приложения и чистятся в истории (последние 20).
- **SSH:** лимит теперь и на выполнение удалённой команды, сессия закрывается по `SIGKILL`.
- **Стриминг:** `ResponseHeaderTimeout` 90 сек — мёртвый хост отваливается сразу, а не ждёт
  stall-watchdog 10 минут.
- **Новости провайдеров:** ссылки ведут на человеческие страницы (список моделей OpenRouter,
  страница цен Z.AI, URL самой статьи в блоге), пустая ссылка не открывает вкладку.

> Номер версии тот же, поэтому уже установленная 0.7.2 обновление из приложения не предложит —
> архив нужно скачать вручную (или пересобрать локально).
