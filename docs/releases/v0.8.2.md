## NotCursor 0.8.2 — nc.ai

### Приватное не попадает в чат (расширено)

- **Падежи**: «логином Вася», «паролем СуперВася» — теперь маскируются, а не
  проходили как есть.
- **JSON-аргументы**: `"user": "papatramp"`, `"login": "…"`, `"username": "…"`
  маскируются; раньше прятался только `"password"`.
- **URL-креденшелы**: `https://user:pass@host` → `https://***@host` (и логин, и
  пароль); `git clone https://user:pass@…`, `curl -u` и т.п. больше не светятся.
  Схема `git@github.com:team/repo.git` (без пароля) не трогается.
- **Basic-auth**: `Authorization: Basic <base64>` → `Authorization: Basic ***`.
- Русские формы `парол*` / `логин*` / `пользовател*` — в любом падеже.

Маскируется только отображаемый текст: команды выполняются и модель получает
реальные значения.

### Убрана вечная плашка из ленты

Строка «СИСТЕМА ⟳ Приложение перезапущено после обновления X → Y» больше не
дублируется в историю чата. Остаётся одноразовый закрываемый баннер сверху.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.8.2-windows-amd64.zip` и распаковать в любую папку.
2. Запустить `NotCursor.exe`.
