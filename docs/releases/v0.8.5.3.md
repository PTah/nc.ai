## NotCursor 0.8.5.3 — nc.ai

### Обновления можно качать со своего зеркала, а не только с GitHub

В `Settings → Обновления` появился выбор источника: **GitHub** (по умолчанию, как раньше) или
**Своё зеркало**. Нужно это для простого случая: GitHub из России отдаёт файлы медленно —
замер на одном и том же архиве 0.8.5.2: **145 секунд** с GitHub против **0,87 секунды** с
домашнего Gitea по локальной сети (разница ~160×).

Как это работает:

- указываешь корень репозитория на зеркале (например
  `http://192.168.x.x:3000/PapaTramp/nc.ai`), приложение проверяет релизы **сначала там**;
- если зеркало недоступно (ноутбук не дома) — **тихий откат на GitHub**, ничего не ломается;
- ссылки на файлы приложение строит от адреса зеркала само: Gitea отдаёт их со своего
  публичного домена, а нам нужен быстрый локальный адрес;
- имена файлов и проверка подписи те же и обязательны: сравнивается sha256 бинарника **внутри**
  архива с `.sha256` рядом с архивом, поэтому «зеркало не то» не проедет;
- в `agent.log` пишется, откуда пришёл релиз (`update check source=mirror latest=… available=…`),
  а в настройках видно, что проверяли зеркало.

Приватность: адрес зеркала и токен (нужен только для приватного зеркала) хранятся **только в
настройках этой машины**, токен — в системном хранилище секретов (Keychain / Credential Manager).
В публичную сборку и в репозиторий ничего из этого не попадает: у остальных пользователей поля
пустые, источник по умолчанию — GitHub, и о твоём Gitea они не узнают.

### Мелочи

- Релизы теперь дублируются не только в GitHub, но и в home (Gitea) — скачивание оттуда по LAN
  занимает долю секунды.
- `internal/update`: релиз читается через общий интерфейс источника (GitHub / Gitea), у `Info`
  появилось поле `source`, а у зеркала — поддержка `token` для приватных репозиториев.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.8.5.3-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
2. Ключи провайдеров — **Settings → Providers** (Windows Credential Manager).

### Установка (macOS 12+, Apple Silicon и Intel)

1. Скачать `nc.ai-0.8.5.3-macos-arm64.zip` или `nc.ai-0.8.5.3-macos-universal.zip`, распаковать.
2. Перенести `NotCursor.app` в «Программы», запустить (ad-hoc подпись: правый клик → «Открыть»).
