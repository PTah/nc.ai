## NotCursor 0.8.7.5 — nc.ai

### Кольцо «идёт работа» у проекта: видно и без анимации

Симптом: у имени проекта, в котором идёт работа, вместо вращающегося кольца рисовался неподвижный
кружок — по нему нельзя было понять, что прогон идёт.

**Причина найдена и она не в последних релизах.** В `frontend/src/App.css` с 0.7.7 (коммит
`8888459`) живёт правило доступности:

```css
@media (prefers-reduced-motion: reduce) {
  .nc-spin { animation: none; border-top-color: currentColor; }
}
```

Оно было написано для того, чтобы уважать системную настройку «уменьшить движение»: вращение
выключается, а разомкнутое кольцо замыкается в ровный круг — чтобы не выглядело «сломанным».
Побочный эффект: если в Windows выключены «Эффекты анимации» (Параметры → Специальные возможности
→ Визуальные эффекты), браузер отдаёт `prefers-reduced-motion: reduce`, и индикатор работы
превращается в статичный кружок — ровно то, что видно на скриншоте.

Что сделано:

- вращение по-прежнему убирается (доступность не ломаем), но вместо `animation: none` кольцо
  **медленно пульсирует** (`nc-work-pulse`, 1.4s, только `opacity`, без поворота — вестибулярного
  раздражителя нет);
- кольцо в этом режиме рисуется акцентным цветом и чуть толще, разрыв кольца сохранён;
- работающий проект дополнительно помечен **по имени**: `.nc-project-btn.busy .nc-project-name` —
  акцентный цвет и полужирный. Это видно вообще без анимации, так что «что-то идёт» читается даже
  при полностью выключенных эффектах.

Замечание: если хочется вернуть именно вращение, достаточно включить Windows → Параметры →
Специальные возможности → Визуальные эффекты → **Эффекты анимации**. Приложение начнёт получать
`no-preference` и снова будет крутить кольцо.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.8.7.5-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
2. Ключи провайдеров — **Settings → Providers** (Windows Credential Manager).

### Установка (macOS 12+, Apple Silicon и Intel)

1. Скачать `nc.ai-0.8.7.5-macos-*.zip`, распаковать.
2. Перенести `NotCursor.app` в «Программы», запустить (ad-hoc подпись: правый клик → «Открыть»).
