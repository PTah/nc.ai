# NotCursor 1.1.18

Две дырки из роадмапа закрыты: резервный провайдер теперь настраивается в UI, а hosted MCP-серверы
без динамической регистрации клиента можно подключить, вписав свой `client_id`.

## Резервный провайдер в настройках

Settings → **Provider** → поле **Резерв** (список провайдеров, «— нет —» = выключено) и
**Резерв: модель** (пусто = модель резервного провайдера по умолчанию).

- Настройка применяется сразу, без перезапуска: `SaveFallbackProvider` / `SaveFallbackModel`.
- Активный провайдер в списке резерва не показывается — одинаковый провайдер в резерв не ставится.
- Резерв включается один раз за запрос: длинный лимит (`429`) или перегрузка основного провайдера.
- В `settings.json` это те же `fallbackProvider` / `fallbackModel`, что и раньше.

## MCP: `client_id` для провайдеров без DCR

В карточке любого HTTP-сервера появилось поле **client_id**.

- Пусто — как раньше: динамическая регистрация клиента (DCR), если сервер её поддерживает.
- Задано — используется этот `client_id`, DCR не вызывается; сохранённый ранее `client_id`
  перекрывается.
- Если DCR нет и поле пустое — понятная ошибка «впишите client_id провайдера в карточку сервера».

Проверено вживую на `api.suno.com/mcp`: discovery `/.well-known/oauth-protected-resource` →
`studio-api-prod.suno.com/api/v2/external/oauth`, DCR выдаёт `client_id`, authorize-ссылка собирается
с PKCE S256, `resource` и локальным `redirect_uri`.

## Проверки

- `internal/mcp/oauth_test.go`: ручной `client_id` без DCR (DCR не вызывается, `client_id` из карточки
  уходит в authorize-ссылку и сохраняется) и ошибка, когда нет ни DCR, ни `client_id`.
- Живые тесты (тег `live`, требуют сети/ключей):
  - `go test -tags live ./internal/mcp -run LiveSuno` — discovery + DCR + authorize-ссылка на Suno;
  - `go test -tags live ./internal/agent -run Live` — провайдеры отвечают, реальный DeepSeek
    подхватывает прогон после длинного `429` у основного.

## Что осталось ручным

- Полный сценарий «OpenRouter free-tier → DeepSeek»: на рабочем ПК ключа OpenRouter нет.
- OAuth на Suno до конца: согласие в браузере и трек из чата (нужен аккаунт Suno).
