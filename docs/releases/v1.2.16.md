## NotCursor 1.2.16 — nc.ai

### Qwen: endpoint Token Plan

В Settings → Provider → **Qwen (DashScope)** третий маршрут рядом с intl / cn:

| Endpoint | Base URL | Ключ |
|---|---|---|
| International | `dashscope-intl.aliyuncs.com/compatible-mode/v1` | `sk-…` / `sk-ws-…` |
| China | `dashscope.aliyuncs.com/compatible-mode/v1` | `sk-…` / `sk-ws-…` |
| **Token Plan** | `token-plan.maas.qwencloudapi.com/compatible-mode/v1` | `sk-sp-…` (QwenCloud) |

Ключ и endpoint должны совпадать. Модель — из списка вашего Token Plan.

Подробности: [docs/exchange-protocols/qwen.md](../exchange-protocols/qwen.md).

### Установка

macOS: `nc.ai-1.2.16-macos-arm64.zip` (Apple Silicon) или `nc.ai-1.2.16-macos-universal.zip`
(Intel + Apple Silicon), распаковать в `/Applications`.
Windows 10/11 x64: `nc.ai-1.2.16-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
