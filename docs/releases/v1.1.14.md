## NotCursor 1.1.14 — nc.ai

### Что изменилось

Исправление к 1.1.13: в workspace из нескольких папок прогон мог оборваться через ~6 секунд
с сообщением «прогон завершён, сигнал не дошёл», хотя бэкенд ещё только строил дерево и индекс
символов по всем папкам.

- **Маркер активного прогона ставится сразу**, до тяжёлой подготовки (дерево файлов, индекс
  символов по каждой папке, подключение MCP — до 20 с). Раньше `ActiveRuns` заполнялся только
  внутри горутины прогона, и watchdog успевал решить, что прогон закончился.
- **Снятие маркера не теряется**: если подготовка падает до передачи прогона в горутину, маркер
  снимается через `defer` — «занято» не остаётся висеть навсегда.
- **Паника внутри прогона больше не оставляет чат занятым**: сообщение уходит в лог и в чат
  (`error` + `persist`), дорожка закрывается — тот же симптом, но раньше без объяснений.

Для проекта из одной папки поведение не меняется: маркер ставится так же рано и снимается тем же
путём, что и раньше.

### Тесты

- `app_runmarker_test.go`: маркер ставится и снимается по сессиям, `ActiveRuns` не смешивает
  параллельные прогоны.
- Прогон: `go vet ./...`, `go test ./...` — зелёные целиком.
