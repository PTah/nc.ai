## NotCursor 0.8.5.1 — nc.ai

### MCP: автоустановка пресетов + верные команды

- Кнопка пресета в Settings → MCP **скачивает** пакет и пишет сервер в настройки:
  - Codebase Memory — `npm install -g codebase-memory-mcp`
  - Code Review Graph — `pip install --user code-review-graph` → `… serve`
  - CodeGraph — `npx -y @agntk/codegraph-mcp`
  - Cognee — `uvx cognee-mcp@latest`
- Пресеты сверены с upstream README; allowlist tools из пресета сразу включён.
- В системный промпт агента — порядок: граф/память → read_file (не слепой grep).
- Документ: [`docs/mcp-coding-servers.md`](../mcp-coding-servers.md).
