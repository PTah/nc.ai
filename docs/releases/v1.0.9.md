## NotCursor 1.0.9 — nc.ai

### Что изменилось

Фоновая проверка теперь не просто сообщает об обновлении, а сама подтягивает файлы.

- Если после `git fetch` репозиторий отстаёт (`behind > 0`) и рабочее дерево **чистое**, без
  локальных коммитов (`changed = 0`, `ahead = 0`), выполняется `git pull --ff-only --quiet` —
  скрыто, без консольного окна и интерактивных запросов (`GIT_TERMINAL_PROMPT=0`, таймаут 60 с).
- При успешном обновлении сообщение в чат **не пишется** — файлы просто обновлены.
- Если есть локальные изменения/коммиты, автопул не делается, и в чат проекта пишется
  служебная строка с причиной. Если `pull --ff-only` не удался (конфликт и т.п.) — тоже
  сообщение.

### Проверка

- `go build ./...` — ок.

### Ограничения

- Только fast-forward: merge и разрешение конфликтов автоматически не делаются.
- Грязное дерево и свои коммиты не трогаются намеренно.
