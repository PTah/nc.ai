## NotCursor 1.0.0 — nc.ai

### Что это за релиз

Первый стабильный номер. В 1.0.0 вошло то, что доводилось в 0.9.x, плюс два пункта из
roadmap-добивок:

- **Реальная модель в чипе.** Если провайдер подменил роут (ShareLLM и подобные), в статусе
  показывается имя из `resp.Model`, а не запрошенное.
- **MCP-вызовы подтверждаются как опасные.** Инструменты с именами `mcp__…` проходят через
  `ApproveTool`, как `write_file`/`run_terminal`; при включённом автоподтверждении — без вопросов.

### Что уже есть в 1.0.0 (из 0.9.x)

- Стабильная лента: живой виток только дописывается, прошлые свёрнуты, статус не мигает,
  автопрокрутка один раз на кадр.
- Свой провайдер и модель на каждый чат.
- PDF/Office-вложения текстом (xlsx/docx/pptx/odt/pdf), сканы — с честной пометкой.
- Защита от prompt injection: случайный `<data-…>` тег для вложений, веб-страниц и поиска.
- Анализ новостей с чтением статьи и разбором по четырём пунктам; сворачиваемый «… ИИ»,
  понятный статус в шапке.
- Краткость в system (без преамбул, diff/таблица вместо портянки) и `findings[]` у подагентов.
- Бюджет tool-результатов, EscalationGate на всех провайдерах, стабильный cache-prefix.

### Что осознанно НЕ входит в 1.0.0

- **§5 Переход в другой проект** (`switch_project` + событие `project:switch` + handoff) —
  крупная фича, требует отдельного захода: завершение прогона из тула, событие после `done`,
  обработчик во фронте.
- **§4 diff viewer + LSP-подсказки + разнести `App.tsx` на хуки** — отдельная работа.
- **macOS-артефакты** — собираются на маке и доливаются в тот же релиз.

### Проверка

- `go vet ./...`, `go test ./...` — зелёные.
- `wails build -o NotCursor-1.0.0.exe` — ок; хеш exe внутри архива совпадает с `.sha256`.
