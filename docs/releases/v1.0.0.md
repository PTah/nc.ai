## NotCursor 1.0.0 — nc.ai

### Что это за релиз

Первый стабильный номер. В 1.0.0 вошло то, что доводилось в 0.9.x, плюс оставшиеся пункты
roadmap: переход в другой проект, diff viewer, реальная модель из ответа и подтверждение MCP.

### Что появилось в этом заходе

- **§5 `switch_project`.** Тула в реестре: агент разрешает проект по имени/пути, завершает
  прогон маркером и отдаёт `handoff`. Приложение по событию `project_switch` открывает проект,
  создаёт чат и запускает новый прогон с handoff. Инструменты по-прежнему пинены к корню
  проекта на прогон, поэтому переход не «перетекает» в старый проект.
- **§4 diff viewer.** Результат `git_diff` в карточке инструмента рисуется построчно: добавления
  зелёным, удаления красным, хунки и мета — приглушённо, вместо серой стены.
- **§4 реальная модель.** Если провайдер подменил роут (ShareLLM и подобные), в чипе показывается
  имя из `resp.Model`.
- **§2 MCP-вызовы** (`mcp__…`) проходят через `ApproveTool` как опасные; автоподтверждение
  по-прежнему снимает вопрос.

### Что уже есть в 1.0.0 (из 0.9.x)

- Стабильная лента: живой виток только дописывается, прошлые свёрнуты, статус не мигает,
  автопрокрутка один раз на кадр.
- Свой провайдер и модель на каждый чат.
- PDF/Office-вложения текстом (xlsx/docx/pptx/odt/pdf), сканы — с честной пометкой.
- Защита от prompt injection: случайный `<data-…>` тег для вложений, веб-страниц и поиска.
- Анализ новостей с чтением статьи и разбором по четырём пунктам; сворачиваемый «… ИИ»,
  понятный статус в шапке.
- Краткость в system и `findings[]` у подагентов.
- Бюджет tool-результатов, EscalationGate на всех провайдерах, стабильный cache-prefix.

### Что осознанно НЕ входит в 1.0.0

- **§4 LSP-подсказки** — нужен LSP-клиент (запуск сервера, JSON-RPC, диагностика в UI): отдельная
  подсистема.
- **§4 разнести `App.tsx` на хуки** — рефакторинг ~9000 строк, отдельная работа.
- **macOS-артефакты** — собираются на маке и доливаются в тот же релиз.

### Проверка

- `go vet ./...`, `go test ./...` — зелёные.
- `wails build -o NotCursor-1.0.0.exe` — ок; хеш exe внутри архива совпадает с `.sha256`.
- `switch_project`: тест на парсер маркера и разрешение проекта по имени/пути.
