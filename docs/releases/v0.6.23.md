## NotCursor 0.6.23 — nc.ai

### Новый провайдер: Qwen (Alibaba Cloud DashScope)

Добавлен провайдер **Qwen** — через OpenAI-совместимый режим Alibaba Cloud Model Studio (DashScope).
Формат тот же, что у DeepSeek/OpenRouter, поэтому tool calling работает «из коробки».

- регион на выбор: **International** (`dashscope-intl…`) или **China** (`dashscope…`) —
  Settings → Provider → Qwen (DashScope);
- модели: `qwen-max`, `qwen-plus`, `qwen-turbo`, `qwen3-coder-plus/flash`, `qwen-vl-max/plus`;
  список подтягивается из `/models`, есть curated-фолбэк и поле для своего model id;
- **Auto-models для Qwen**: `qwen-plus` по умолчанию → `qwen-max` на сложных задачах и длинных
  прогонах; картинки → `qwen-vl-max`;
- ключ хранится в Windows Credential Manager / macOS Keychain; расходы (токены и стоимость) считаются
  отдельным счётчиком Qwen в чате и в топбаре;
- особенность DashScope: баланса через API нет (для Qwen индикатор скрыт), а `usage.cost` в ответе не
  приходит — стоимость считаем по тарифу на стороне приложения.

### Логика окна пошагового ToDo

- ToDo-план агента больше **не висит полосой сверху** окна ответов — теперь он живёт **внутри ленты**,
  в конце потока, как часть обсуждения;
- блок **сворачивается за треугольником** (как `Thinking…` и группы инструментов), в заголовке
  сводка вида `Todo · 3/5`;
- пока есть незавершённые пункты — блок раскрыт; когда всё выполнено или отменено — **сам
  сворачивается** до одной строки, чтобы не мешать; развернуть и свернуть можно вручную.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.6.23-windows-amd64.zip` и распаковать в любую папку.
2. Запустить `NotCursor.exe` (бинарник не подписан: SmartScreen → «Подробнее» → «Выполнить в любом
   случае»).
3. Ключи провайдеров — **Settings → Providers** (хранятся в Windows Credential Manager).
