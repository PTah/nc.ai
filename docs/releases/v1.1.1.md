## NotCursor 1.1.1 — nc.ai

### Зачем

Два оставшихся приёма из DreamTeam, которые полезны без «кучи денег на токены»:
потолок расходов с паузой и зависимости задач в todo.

### Что появилось

- **Потолок денег с паузой (#4).** В Settings → Agent рядом с «Max tool steps» — поле
  «Потолок расходов на прогон, $» (`maxCostUsd`, 0 = без потолка). После каждого usage
  стоимость прогона суммируется; при достижении потолка в чат уходит один notice «Достигнут
  потолок $X — остановился. Отправь сообщение, чтобы продолжить», и прогон отменяется.
  История сохраняется — продолжение новым сообщением.
- **Зависимости задач (#3).** У пункта `todo_write` появилось поле `blockedBy` — id задачи,
  от которой зависит пункт; пусто — можно брать сразу. При `merge` незаполненное значение
  сохраняется. Модель видит зависимости в JSON todo и не берётся за заблокированные пункты.

### Проверка

- `go build ./...`, `go test ./internal/tools/ ./internal/config/` — зелёные.
- `wails build` с перегенерацией биндингов (`SaveMaxCostUSD`) — ок.

### Ограничения

- Маркер «⛔ ждёт» в UI todo не добавлен — зависимости видны модели, не интерфейсу.
- Потолок считается по стоимости прогона (сессия), а не по всему аккаунту.
