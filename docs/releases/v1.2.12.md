## NotCursor 1.2.12 — nc.ai

### Стабильность длинных чатов

- Огромные tool-выводы и `data:`-картинки при сохранении обрезаются (200 000 символов / 200 КБ) с
  пометкой — файл чата больше не раздувается до мегабайт, а старые сообщения остаются открываемыми.
- Автосохранение транскрипта дебаунсится до 1500 мс (на завершении прогона, переключении чата и
  `beforeunload` — мгновенно). Меньше перезаписей всего бандла проекта.
- Лента рендерит последние 400 элементов с кнопкой **«Показать раньше · ещё N сообщ.»** (+400 за клик):
  длинные чаты больше не создают тысячи DOM-узлов и не подвешивают WebView2.

### Про «обрывы связи»

Если в чате появляется ошибка соединения — это сеть: соединение к `api.deepseek.com` может рваться
(DPI/маршрут). Помогает Settings → Network (HTTP/1.1, keepalive, reconnect attempts/budget), резервный
провайдер (Settings → Provider → Fallback) и, при DPI, VPN/прокси. Код приложения тут ни при чём —
сам процесс не падает (в логе нет паники, в журнале Windows — падений `NotCursor.exe`).

### Установка

macOS: `nc.ai-1.2.12-macos-arm64.zip` (Apple Silicon) или `nc.ai-1.2.12-macos-universal.zip`
(Intel + Apple Silicon), распаковать в `/Applications`.
Windows 10/11 x64: `nc.ai-1.2.12-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
