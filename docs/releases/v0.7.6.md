## NotCursor 0.7.6 — nc.ai

### Кнопка «Проверить обновления» действительно снимает баннер

После установки 0.7.5 в шапке висел баннер «Версия 0.7.5 та же, но на GitHub другая сборка», и кнопка
**Проверить обновления** в настройках его не убирала. Причина не в GitHub и не в логике проверки:
свежая проверка предложения не давала, но интерфейс при этом **не сбрасывал прошлое состояние** —
старый баннер оставался на экране, и кнопка выглядела сломанной.

- Ручная проверка теперь обнуляет предложение, если свежий ответ — «обновлений нет»: баннер
  исчезает сразу, а в настройках появляется строка «Обновлений нет — установлена последняя версия
  0.7.6 (ваша сборка 12-символьный хеш)».
- То же и на стороне приложения: после ручной проверки без предложения кеш «доступен апдейт»
  очищается, чтобы кнопка «Скачать» из старого баннера не переустанавливала ту же версию.
- В самом баннере «та же версия, другая сборка» теперь видно оба хеша: `ваш файл <хеш>, на GitHub
  <хеш>` — сразу понятно, разошлись ли сборки (при копии релиза из `build/bin` они совпадают).

### Причина того баннера (на заметку)

В релиз 0.7.5 был положен `.sha256` с хешем **архива**, а апдейтер сравнивает хеш **бинарника внутри
архива** (`LocalExeHash`). Пока хеши не совпадают, приложение считает сборку «другой». Sidecar
перезалит правильно, а чтобы ошибка не повторялась, в репозитории появился
`scripts/macos-zip-sidecar.sh`: `./scripts/macos-zip-sidecar.sh <zip>...` пишет sidecar из содержимого
архива, `--check <zip> <exe>` сверяет его с локальным файлом.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.7.6-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
2. Ключи провайдеров — **Settings → Providers** (Windows Credential Manager).

### Установка (macOS 12+, Apple Silicon и Intel)

1. Скачать `nc.ai-0.7.6-macos-arm64.zip` или `nc.ai-0.7.6-macos-universal.zip`, распаковать.
2. Перенести `NotCursor.app` в «Программы», запустить (ad-hoc подпись: правый клик → «Открыть»).
