## NotCursor 0.8.7.9 — nc.ai

### Хвост ответа больше не теряется

Найдено точное место потери. По данным сохранённой сессии: в `history` (то, что видит модель)
ответ был **2051** символ и заканчивался правильной фразой, а в `itemsJson` (то, из чего рисуется
чат) — **1989**, то есть **не доехало ровно 62 символа** — последний кусок. Модель дописала, бэкенд
сохранил, терялся хвост на пути к элементу чата.

Что сделано:

- **подстраховка на завершении прогона**: при событии `done` элемент чата доводится из буфера
  дельт (только в сторону роста — более длинный текст не затирается). Если последний чанк не успел
  примениться, хвост восстанавливается;
- **диагностика доставки**: бэкенд теперь передаёт в событии `done` длину итогового ответа
  (`answerLen`), а интерфейс сверяет её с тем, что реально дошло. При расхождении в чат пишется
  строка вида «⚠ Диагностика: бэкенд выдал 2051 симв., до чата дошло 1989» — то есть в следующий
  раз причина будет видна сразу, без раскопок по файлам сессии.

### Релизы Windows и macOS больше не затирают друг друга

Релизный скрипт собирал релиз заново: удалял существующий и создавал новый, вместе с ассетами.
Пока релизы делались с одной машины, это было незаметно, но теперь Windows собирается здесь, а
macOS — на mac, и удаление стирало чужие файлы.

- если релиз с таким тегом **уже есть**, скрипт не удаляет его, а правит заголовок с заметками и
  **доливает свои ассеты** (`gh release upload --clobber` для GitHub; для Gitea — обновление релиза
  через `PATCH` и замена одноимённого ассета вместо создания дубля);
- ассеты других платформ остаются на месте;
- релиз создаётся только если его ещё нет.

Заодно в скрипте ужесточена проверка архивов: при выкладке zip всегда пересобирается из
`build\bin`, и релиз падает с ошибкой, если хеш exe внутри архива не совпал с подписью `.sha256`
(иначе приложение вечно предлагает «обновиться», а скачивание не помогает).

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.8.7.9-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
2. Ключи провайдеров — **Settings → Providers** (Windows Credential Manager).

### Установка (macOS 12+, Apple Silicon и Intel)

1. Скачать `nc.ai-0.8.7.9-macos-*.zip`, распаковать.
2. Перенести `NotCursor.app` в «Программы», запустить (ad-hoc подпись: правый клик → «Открыть»).
