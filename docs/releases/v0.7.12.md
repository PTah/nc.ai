## NotCursor 0.7.12 — nc.ai

Провайдер **Yandex AI Studio** в Settings, баланс **DeepSeek** в шапке и DeepSeek Auto: эскалация Flash → Pro.

### Yandex AI Studio

В **Settings → Provider** появился пункт **Yandex AI Studio**. Подключение через
OpenAI-совместимый gateway:

- Base URL: `https://ai.api.cloud.yandex.net/v1`
- Auth: `Authorization: Api-Key <ключ>`
- Folder ID каталога Yandex Cloud (`x-folder-id` / OpenAI `project`)
- Модель в API: `gpt://<folder>/<model>/latest` (в UI — короткое имя)

Что указать в настройках:

1. API-ключ сервисного аккаунта (scope `yc.ai.languageModels.execute`)
2. Folder ID
3. Модель: `yandexgpt`, `yandexgpt-lite`, `qwen3-235b-a22b-fp8`, `gpt-oss-120b` и др.

Auto-models: `yandexgpt` по умолчанию, на сложных задачах — `qwen3-235b-a22b-fp8`.
Стриминг и tool calling работают как у остальных OpenAI-совместимых провайдеров.
Баланса через API нет — смотрите биллинг Yandex Cloud; стоимость в UI приблизительная (USD).

Документация протокола: `docs/exchange-protocols/yandex.md`.

### DeepSeek Auto: эскалация Flash → Pro

При активном **DeepSeek + Auto-models**:

- префикс `/pro` или `[pro]` в начале сообщения — сразу Pro на этот прогон;
- mid-run подъём на Pro (только вверх, до конца прогона), если:
  - два раза подряд один и тот же tool call,
  - два провала инструментов подряд (`ERROR:` / `DENIED`),
  - пустой ответ модели,
  - битый tool JSON;
- session-sticky на Flash сбрасывается, если новый запрос сложный или с `/pro`.

В ленте — notice с причиной переключения; в `agent.log` — `escalate model=… reason=…`.

### Баланс DeepSeek

При активном провайдере DeepSeek приложение запрашивает
`GET https://api.deepseek.com/user/balance` и показывает:

- **bal** — общий остаток (`total_balance`)
- **grant** — грантовый баланс (`granted_balance`)
- **topup** — сумма пополнений (`topped_up_balance`)

Валюта — USD или CNY (как в ответе API). В Settings → DeepSeek есть кнопка
**Refresh balance**. Детальная статистика токенов по-прежнему только на
[platform.deepseek.com/usage](https://platform.deepseek.com/usage).

### Исправления

- Отложенная отправка: запрос, введённый во время прогона, теперь гарантированно
  стартует после его завершения. Очередь дренируется с повтором при transient-занятости,
  а ошибка запуска не зацикливает автоповтор (вопрос остаётся в ленте с Retry).

### Установка

Скачайте zip под свою платформу, распакуйте и замените приложение.
На macOS (Apple Silicon) апдейтер берёт `-arm64.zip`; sidecar `.sha256` — хеш
исполняемого файла внутри архива, не самого zip.
