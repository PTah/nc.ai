## NotCursor 0.9.7 — nc.ai

### Зачем

Три вещи из практики: лента во время прогона дёргалась, провайдер был общим на все чаты, а
ответы бывали длиннее, чем нужно.

- Живой виток пересобирался на каждом шаге (`running → done → tool_group → process`), а на
  старте прогона раскрывались все прошлые витки — отсюда прыжки и «разноцветные вставки»,
  которые то появлялись, то исчезали.
- Провайдер выбирался только глобально: два чата не могли работать на разных провайдерах.
- Системный промпт просил «кратко», но не запрещал преамбулы и пересказ tool-результатов.

### Что появилось

- **Лента стабильна.** Живой виток (после последнего сообщения пользователя) — строго
  append-only: без перегруппировок и свёрток. Прошлые витки всегда остаются свёрнутыми,
  статус не мигает, автопрокрутка — один `requestAnimationFrame` на изменение, а не несколько
  синхронных «прыжков вниз». Финальная компакция — один раз по завершении.
- **Свой провайдер и модель на каждый чат.** `Session.ProviderID`, `SetSessionProvider`,
  фабрика `buildProviderFor` (не трогает глобальный `a.llm`), провайдер на прогон берётся из
  сессии. В шапке композера — селектор провайдера рядом с моделью; список моделей следует за
  выбранным провайдером.
- **Краткость в system (E4).** Без преамбул и пересказа вопроса; diff/таблица вместо портянки;
  не вставлять обратно уже показанный tool-результат; длиннее ~25 строк — результат + ссылка на
  файл. Не конфликтует с «отвечай на языке пользователя».
- **Подагенты отдают `findings[]` (E5).** Контракт `{category, severity, file, message}`;
  родитель получает и `summary`, и машинный список замечаний. В system добавлена подсказка
  предпочитать несколько узких `task` одному широкому.

### Проверка

- `go vet ./...`, `go test ./...` — зелёные.
- `wails build` — ок; TS-биндинги перегенерированы (`SetSessionProvider`).

### Ограничения

- §1 закрыт частично: провайдер и модель на чат есть; статус-бар/стоимость пока из глобальных
  счётчиков, не из сессии.
- Селектор провайдера перечисляет пять облачных провайдеров; локальные профили — отдельным шагом.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.9.7-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
2. Запустить длинный прогон — лента должна расти вниз без прыжков.
3. В композере выбрать провайдера и модель для конкретного чата.
