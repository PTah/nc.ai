## NotCursor 1.0.10 — nc.ai

### Зачем

`ssh_exec` на каждый вызов открывал новое SSH-соединение — сервер присылал по
одному «Successful SSH login» на шаг, а зависшая сессия жила отдельно. Теперь соединение
переиспользуется.

### Что изменилось

- `internal/sshx`: пул открытых соединений по ключу `host|port|user|identity`.
- `Exec` берёт уже установленное соединение и открывает на нём только канал, не делая
  повторный логин.
- Соединение закрывается по простою (10 минут) фоновым `reapLoop`, а не после каждой команды.
- Таймаут команды больше не убивает общее соединение — только канал; соединение приберёт
  reaper.

### Проверка

- `go build ./...` — ок.
- `go test ./internal/sshx/ ./internal/tools/` — зелёные.

### Ограничения

- Соединение живёт до 10 минут после последней команды; если нужен мгновенный выход —
  закроется следующим проходом reaper (каждые 2 минуты).

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-1.0.10-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
