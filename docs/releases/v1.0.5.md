## NotCursor 1.0.5 — nc.ai

### Новости Kimi в дайджесте

Kimi (Moonshot) стал пятым источником «Новостей провайдеров» — рядом с DeepSeek, Z.AI, OpenRouter и Qwen.

| Что | Как |
|---|---|
| Источник | `platform.kimi.ai/docs/platform-changelog.md` — официальный changelog Kimi Open Platform |
| Почему `.md` | HTML-страница собирается Next.js (контент в `self.__next_f`), а markdown-вариант отдаёт тот же текст разметкой: месяц строкой `**October 2026**`, записи — `### Заголовок` или пункты `* текст` |
| Дата записи | точного дня в changelog нет — берётся первое число месяца (`2026-10-01`), этого достаточно для сортировки и подписи |
| Заголовок | markdown вычищается: `[Kimi K3](https://…)` → `Kimi K3`, снимаются кавычки, `**`, `*`; длина ограничена 160 символами |
| Ссылка | всегда на сам changelog (в записях нет отдельных постоянных ссылок) |

### Дайджест больше не перекашивает

Пятый источник приносит длинную историю (около 40 записей с 2024 года). Раньше единственным
ограничением был общий размер 60 записей после сортировки по дате — старые записи Kimi вытеснили бы
свежие новости остальных провайдеров. Теперь есть лимит **12 записей на провайдера** (`MaxPerProvider`),
после него — общий лимит 60.

### Проверка

- новые тесты: `internal/providernews/kimi_test.go` (разбор changelog, чистка markdown, месяцы),
  `internal/providernews/perprovider_test.go` (лимит на провайдера);
- `go test ./internal/providernews ./internal/appmeta` — зелёные, `go build ./...` — без ошибок;
- на реальном ответе `platform.kimi.ai/docs/platform-changelog.md` структура совпадает с разбором:
  `**October 2026**` → `### 📦 Batch API now supports Kimi K3.1 Pro and Kimi K3` и т.д.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-1.0.5-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
2. Ключи провайдеров — **Settings → Providers**.

### Установка (macOS 12+, Apple Silicon и Intel)

1. Скачать `nc.ai-1.0.5-macos-*.zip`, распаковать.
2. Перенести `NotCursor.app` в «Программы», запустить (ad-hoc подпись: правый клик → «Открыть»).
