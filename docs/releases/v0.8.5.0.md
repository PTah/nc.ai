## NotCursor 0.8.5.0 — nc.ai

### MCP-клиент (MVP, §2a) + пресеты code-graph (§2b)

Внешние инструменты без правок ядра агента: stdio JSON-RPC, Settings → **MCP**.

- Запуск сервера: `initialize` → `tools/list` → выборочный allowlist в промпт.
- Имена: `mcp:<serverId>:<tool>` — вызываются из обычного agent loop.
- Env дочернего процесса фильтруется (наши `*_API_KEY` не утекают).
- Пресеты: **Code Review Graph**, **CodeGraph Context**, **Codebase Memory**, **Cognee**.
- По умолчанию tools в промпт **не** попадают — отметьте после «Проверить».

HTTP/SSE/OAuth — следующие этапы (`docs/mcp.md`).

### Как попробовать

1. Settings → MCP → пресет (например CodeGraph).
2. Включить сервер, «Проверить», отметить нужные tools.
3. В чате попросить найти модуль через граф / память, затем точечный `read_file`.
