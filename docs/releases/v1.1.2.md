## NotCursor 1.1.2 — nc.ai

### Что появилось

- **Маркер «⛔ ждёт» в todo.** Если у пункта заполнен `blockedBy` и он не выполнен/не отменён,
  рядом с текстом появляется «⛔ ждёт» с подсказкой «Ждёт задачу <id>». Зависимости из
  `todo_write` теперь видны и в интерфейсе, а не только модели.
- **Чужое ревью перед «готово».** В системный промпт добавлено правило: перед объявлением
  правки завершённой запускать один узкий `task` на ревью `git diff` (баги, пропущенные
  случаи, безопасность) и показывать его `findings[]`. Решение «принять / вернуть» — за
  пользователем.

### Проверка

- `go build ./...` — ок.
- `npm --prefix frontend run build` — ок.
- `wails build` — ок.

### Ограничения

- Кнопки «Принять/Вернуть» в чате пока не добавлены: ревью приходит с `findings[]`, решение
  пользователь высказывает сообщением. Это следующий UI-шаг.
