## NotCursor 1.2.17 — nc.ai

### Состояние прогона у проекта

В списке проектов видно, что происходит с работой:

| Индикатор | Значение |
|---|---|
| кольцо (крутится) | в проекте идёт прогон — даже если открыт другой проект |
| ✓ | прогон в проекте завершён; галочка держится, пока проект не откроют или не запустят в нём новую работу |

Раньше после завершения прогона у названия проекта не оставалось ничего, и при нескольких
проектах было не понять, где работа уже закончилась.

### Короткие имена чатов

Чат больше не остаётся «Chat 2»: при первом вопросе имя берётся из него же — как в Cursor.
Код, ссылки и markdown выкидываются, берётся первая фраза, обрезка по границе слова (до 56
символов). Имя, заданное вручную (двойной клик по вкладке), автоматика не трогает.

### MCP-процессы: без сирот

- Установщики пакетов (`npm install -g`, `pip`, `uvx`) теперь запускаются через тот же guard,
  что и MCP-серверы: Job Object на Windows / своя process group на Unix. Раньше таймаут
  установки гасил только `cmd.exe`, а `node.exe` оставался в памяти.
- Сервер, упавший сам (краш, OOM, исчезла обёртка npx), сразу забирает с собой всё дерево
  потомков, а не ждёт нажатия Stop или выхода из приложения.
- Фоновый старт MCP после остановки приложения больше не воскрешает сервер.

### Установка

macOS: `nc.ai-1.2.17-macos-arm64.zip` (Apple Silicon) или `nc.ai-1.2.17-macos-universal.zip`
(Intel + Apple Silicon), распаковать в `/Applications`.
Windows 10/11 x64: `nc.ai-1.2.17-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
