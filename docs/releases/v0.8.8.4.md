## NotCursor 0.8.8.4 — nc.ai

### «Этап» больше не показывает сырой JSON

Иногда в ленте появлялись карточки «этап» с техническим мусором вида
`{"phase":"heartbeat","elapsed":"2:30",…}` — это протекали служебные
heartbeat-события агента. Теперь:

- heartbeat только обновляет живую строку статуса и **никогда** не рисуется
  карточкой;
- если событие прогресса не удалось разобрать, оно игнорируется — сырой JSON в
  окно не попадает;
- карточки «этап» сворачиваются под стрелку `▸`: видна одна строка
  («Работа идёт: 2:30 · шаг 3…»), подробности — по клику.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.8.8.4-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
2. Ключи провайдеров — **Settings → Providers** (Windows Credential Manager).

### Установка (macOS 12+, Apple Silicon и Intel)

1. Скачать `nc.ai-0.8.8.4-macos-*.zip`, распаковать.
2. Перенести `NotCursor.app` в «Программы», запустить (ad-hoc подпись: правый клик → «Открыть»).
