## NotCursor 1.0.6 — nc.ai

### Зачем

Набор текста в чате тормозил, кнопки не реагировали: на каждую клавишу пересобиралась вся
лента и заново парсился весь markdown.

### Что изменилось

- `items` и `laneItems` мемоизированы — при вводе массив сообщений больше не пересоздаётся.
- `displayRows` (группировка инструментов, свёртка витков) мемоизирован и не пересчитывается
  на каждый рендер.
- `Markdown` обёрнут в `memo` — блоки с тем же содержимым не перерисовываются и не парсятся
  заново.
- Автопрокрутка не срабатывает на ввод: `items` стабилен, эффект зависит от него.

Набор текста теперь перерисовывает только композер.

### Проверка

- `npm --prefix frontend run build` — ок.
- `wails build -o NotCursor-1.0.6.exe` — ок.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-1.0.6-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
