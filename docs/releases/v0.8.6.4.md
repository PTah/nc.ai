## NotCursor 0.8.6.4 — nc.ai

### «Refresh models» больше не молчит

Клик по кнопке обновления списка моделей раньше выглядел как «ничего не произошло»: результат
писался мелкой серой строкой под кнопкой, а её текст часто совпадал с предыдущим ответом — по
интерфейсу нельзя было понять, перечитался список или нет.

- Кнопка на время опроса показывает **«Обновление…»** и блокируется — видно, что запрос ушёл.
- Результат опроса пишется **в чат** системным сообщением: провайдер, источник (список из API /
  встроенный список / ошибка), число моделей и сами **id** моделей (первые 40, дальше «… ещё N»).
- В чат пишет только **ручной** клик: авто-опрос при старте приложения и при смене провайдера
  ленту не засоряет.
- Работает для всех провайдеров настроек: DeepSeek, Z.ai, OpenRouter, Qwen, Yandex, Custom
  (локальный OpenAI-совместимый эндпоинт).

Пример ответа в чате:

```
Модели OpenRouter: Список из API — моделей: 46.
qwen/qwen3-coder-flash, qwen/qwen3-coder-flash:floor, qwen/qwen3-coder, …
```

### Model prices: у OpenRouter цены на все модели, а не на курированные шесть

Список цен был статичным: у OpenRouter в нём жили шесть заранее отобранных моделей, поэтому
«в списке цен только qwen3-coder» — это было ожидаемое поведение, а не отсутствие цен на сайте
провайдера. OpenRouter публикует `pricing` по всем моделям в `GET /api/v1/models` (публично, без
ключа).

- `ModelInfo` OpenRouter-клиента теперь читает блок `pricing` и отдаёт ставки в USD за 1M токенов
  (prompt / cache read / completion).
- При получении списка моделей провайдера id **и их живые цены** попадают в `internal/costing`
  (`SetOpenRouterCatalog`), а не только выбранная модель.
- «Model prices» строит строки OpenRouter из этого каталога: все модели, которые можно выбрать в
  настройках, с реальными ценами, отсортированные по цене (weak → strong).
- `:floor`-варианты берут цену базовой модели; пока каталог не прочитан, показывается прежняя
  курированная карточка как fallback.
- Фоновое обновление цен учитывает весь каталог, а не только кураторский набор.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.8.6.4-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
2. Ключи провайдеров — **Settings → Providers** (Windows Credential Manager).

### Установка (macOS 12+, Apple Silicon и Intel)

1. Скачать `nc.ai-0.8.6.4-macos-arm64.zip` или `nc.ai-0.8.6.4-macos-universal.zip`, распаковать.
2. Перенести `NotCursor.app` в «Программы», запустить (ad-hoc подпись: правый клик → «Открыть»).
