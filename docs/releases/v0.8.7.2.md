## NotCursor 0.8.7.2 — nc.ai

### Список моделей OpenRouter чистится по живому каталогу

Курированный список id'ов добавлялся в список моделей безусловно — даже если OpenRouter модель
уже снял. Так в настройках продолжал предлагаться `qwen/qwen3-coder-plus`, которого в
`GET /api/v1/models` больше нет (проверено живым запросом), и `qwen/qwen3-vl-32b-instruct`.
Выбрать такую модель — значит отправить запрос на несуществующий id.

- `Catalog()` сверяет каждый курированный id с живым каталогом: нет модели — нет строки.
- Суффиксные варианты (`:floor`) в `/models` не появляются никогда, поэтому проверяются через
  базовый id.
- Модель без `tools` не попадает в курированный блок: агент на ней не поедет. Из общего списка
  она не исчезает — остаётся в своей категории, чтобы UI мог предупредить.
- Живого каталога нет (нет ключа / запрос упал) — показываем курированный список как есть:
  проверять нечем, а список нужен.
- Из курированного списка убраны снятые id: `qwen/qwen3-coder-plus`, `qwen/qwen3-coder-plus:floor`,
  `qwen/qwen3-vl-32b-instruct` (и то же в фолбэке фронтенда, и в прайс-листе OpenRouter).

### Дефолты Auto-models для OpenRouter стали заметно выгоднее

`StrongModel` был `qwen/qwen3-coder:floor` — самый дешёвый апстрим. `:floor` экономит, но выбирает
нижний тир провайдеров, а именно там tool calling и начинает «чудить».

- `StrongModel` → `qwen/qwen3-coder-next` (без `:floor`): свежее поколение, **дешевле** чена
  `qwen3-coder-flash` ($0.12/$0.80 против $0.195/$0.975) и крепче в tool calling.
- Порог длинного прогона: `Step >= 8` → `Step >= 4`. Так как coder-next дешевле flash, сильная
  модель на длинных прогонах не удорожает шаг, зато многошаговые прогоны не сидят на самом слабом
  tool-caller'е.
- Эскалация при затыке теперь поднимает на этот же `qwen/qwen3-coder-next`.
- Дефолт (`qwen/qwen3-coder-flash:floor`) оставлен как есть — это экономия для простых шагов.

### Мелочи

- В прайс-листе у `qwen/qwen3-coder-next` отмечено «Auto complex» (она теперь цель роутинга),
  строка снятого `qwen/qwen3-coder-plus` убрана.
- `docs/exchange-protocols/openrouter.md`: таблица рекомендуемых моделей приведена к актуальной,
  добавлена оговорка про `:floor` и про сверку с каталогом.

### Тесты

`internal/llm/providers/openrouter/catalog_test.go`: снятый курированный id отбрасывается,
модель без `tools` не помечается как курированная, без живых данных курированный список
показывается целиком.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.8.7.2-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
2. Ключи провайдеров — **Settings → Providers** (Windows Credential Manager).

### Установка (macOS 12+, Apple Silicon и Intel)

1. Скачать `nc.ai-0.8.7.2-macos-*.zip`, распаковать.
2. Перенести `NotCursor.app` в «Программы», запустить (ad-hoc подпись: правый клик → «Открыть»).
