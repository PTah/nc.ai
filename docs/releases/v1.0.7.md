## NotCursor 1.0.7 — nc.ai

### Зачем

По мотивам статьи про always-on агента: приложение само следит за новостями и состоянием
репозиториев проектов, без нажатий.

### Что появилось

- **Фоновый цикл** в приложении: тикер раз в 30 минут проверяет, не пора ли обновить новости
  или проверить репозитории; обе задачи — раз в 8 часов.
- **Новости раз в 8 часов.** Обновление идёт тем же путём, что и «Обновить» (включая ИИ-анализ,
  если галочка включена); по завершении приходит событие `news:updated`, и панель новостей
  подхватывает свежий дайджест.
- **Проверка репозиториев проектов.** Сразу после старта (через 2 минуты) и далее раз в 8 часов
  для каждого проекта читается `git status -sb` без сети: ветка, число изменённых файлов,
  ahead/behind относительно upstream. Если что-то есть, в шапке появляется чип «репо: N» с
  расшифровкой в подсказке.
- Проверка репозиториев дешёвая: не делает `git fetch`, только локальные данные.

### Проверка

- `go build ./...` — ок.
- `npm --prefix frontend run build` — ок.
- `wails build -o NotCursor-1.0.7.exe` — ок.

### Ограничения

- Интервал фиксированный (8 часов), без настройки в UI — следующий шаг, если понадобится.
- Ahead/behind считаются по уже известным remote-refs (без `git fetch`), поэтому могут быть
  слегка устаревшими до ручного fetch.
