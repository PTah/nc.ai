## NotCursor 1.0.1 — nc.ai

### Новые записи дайджеста подсвечены

Когда в настройках горит «4 новых», у этих записей кнопка **«… ИИ»** теперь зелёная:

| Тема | Как выглядит |
|---|---|
| Светлая | мягкий зелёный фон (#e4f7ea), тёмно-зелёный текст, зелёная рамка |
| Тёмная | яркий зелёный фон (#3ff08a), почти чёрный текст — кнопка читается сразу |

Как только анализ открыли («… ИИ» → «▴ ИИ»), подсветка гаснет — кнопка становится такой же,
как у остальных записей. Отметка сохраняется в `provider-news.json` (`seenIds`), поэтому после
перезапуска приложения подсветка не возвращается. Список прочитанного ограничен (200 id) и чистится
при обновлении дайджеста — остаются только те записи, которые ещё есть в списке.

### Что под капотом

- `providernews.Item` получил `new` и `seen` — оба флага считаются на лету в `PayloadOf`, в кэш не
  пишутся (кэш остаётся прежним, никакой миграции не требуется);
- `new` = записи не было в предыдущем дайджесте (`PrevIDs`), то есть ровно те записи, которые
  попадают в счётчик «N новых»;
- новый метод `MarkProviderNewsItemSeen(id)` сохраняет отметку в `SeenIDs`; `Refresh` переносит её
  дальше и чистит исчезнувшие id (`pruneSeen`);
- на фронте `MarkProviderNewsItemSeen` вызывается при раскрытии анализа, состояние обновляется
  оптимистично — подсветка гаснет сразу, без ожидания записи на диск.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-1.0.1-windows-amd64.zip`, распаковать, запустить `NotCursor.exe`.
2. Ключи провайдеров — **Settings → Providers**.

### Установка (macOS 12+, Apple Silicon и Intel)

1. Скачать `nc.ai-1.0.1-macos-*.zip`, распаковать.
2. Перенести `NotCursor.app` в «Программы», запустить (ad-hoc подпись: правый клик → «Открыть»).
