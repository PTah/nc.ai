## NotCursor 1.1.3 — nc.ai

### Что появилось

- **Кнопки «Принять / Вернуть» у ревью.** Если узкий `task` вернул `findings[]`, под карточкой
  инструмента появляется блок «Ревью: N замечаний»: severity, файл, сообщение. Кнопка
  **Принять** помечает ревью принятым (✓ принято), **Вернуть** отправляет замечания агенту
  сообщением «Верни на доработку по ревью: …» — без ручного копирования.
- Кнопка «Вернуть» работает в основном списке чата (там, где есть доступ к отправке);
  в свёрнутых группах инструментов она неактивна.

### Проверка

- `npm --prefix frontend run build` — ок.
- `go build ./...` — ок.
- `wails build` — ок.
