## NotCursor 0.7.1 — nc.ai

### Anthropic Messages напрямую

В Settings → Local появился выбор формата API. Раньше профиль умел только
OpenAI-совместимый Chat Completions, теперь есть второй вариант — **Anthropic Messages**
(`POST /v1/messages`):

| Куда | Base URL | Ключ |
|---|---|---|
| Anthropic | `https://api.anthropic.com` | `x-api-key` (в Credential Manager / Keychain) |
| Selora, Atria и другие роутеры | адрес роутера, обычно с `/v1` | тот же `x-api-key` (плюс `Bearer` для роутеров) |

Запрос и ответ переводятся адаптером (`internal/llm/providers/anthropic`), поэтому агент не
замечает разницы: system-промпт уходит отдельным полем, инструменты — через `input_schema`,
их вызовы — блоками `tool_use`, результаты — `tool_result` в user-turn. Картинки из вложений
превращаются в `image`-блоки (`base64` из data URL, `url` из ссылки). Thinking-блоки ответа
попадают в коллапс «Думал», как `reasoning_content` у остальных провайдеров.

Модель можно взять кнопкой из `GET /v1/models` (Selora и Atria отдают список), либо вписать
id руками. Для профиля Anthropic кнопка проверки в настройках больше не ищет VRAM: она
проверяет ключ и `/v1/models` и пишет «Anthropic OK».

Что пока не сделано: стриминга нет (ответ приходит целиком, как у DeepSeek/Z.ai/Qwen), и
thinking обратно не отправляется — подпись блока не сохраняется, поэтому extended thinking
вместе с tools на прямом API не включаем.

### reasoning_effort стал опциональным

Раньше поле не отправлялось никогда (Ollama, vLLM и LM Studio отвечают на незнакомое поле
400). Теперь в профиле эндпоинта есть пункт **Reasoning effort** — `low` / `medium` / `high`:
публичные роутеры включают этим «размышления», а локальные серверы продолжают работать по
умолчанию без него.

### Также в выпуске (с 0.7.0)
- размышления моделей, приходящие инлайном в текст (`<think>…</think>`), отделяются в «Думал»
  и не попадают в ответ и в историю чата;
- лимиты `429` разбираются по `Retry-After` и `x-ratelimit-reset-*`: в чате видно «повтор через
  42 сек», агент ждёт и повторяет сам, суточный лимит не ждёт;
- служебные процессы (`node`, `npm`, `go`, `python`) и `go vet` запускаются скрыто — окна
  cmd/PowerShell больше не мелькают при новом чате;
- план задач уезжает в поток после выполнения и не висит в самом низу окна.

### Что проверить

1. Settings → Local → **Add server**: Base URL `https://api.anthropic.com`, ключ, модель
   `claude-sonnet-4-*`, API format → Anthropic Messages → «Проверить»: «Anthropic OK».
2. Спросить что-нибудь с инструментами (прочитать файл) — вызов и результат проходят как обычно.
3. Приложить картинку — модель её видит.
4. Профиль на роутере (Selora/Atria): тот же ключ, Base URL роутера, `Reasoning effort → high`.

### Установка (Windows 10/11, x64)

1. Скачать `nc.ai-0.7.1-windows-amd64.zip` и распаковать в любую папку.
2. Запустить `NotCursor.exe`.
3. Дальше обновления — кнопкой из приложения.
